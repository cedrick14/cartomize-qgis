# Publication de la bibliothèque Python

La bibliothèque Python Cartomize et le plugin QGIS sont deux projets distincts.

La publication PyPI depuis ce dépôt du plugin est désactivée. La bibliothèque est en cours de préparation dans un dépôt dédié, prévu sous le nom `cedrick14/cartomize-python`. Le paquet Python conserve le nom `cartomize`.

Ne pas configurer `cartomize-qgis` comme éditeur de confiance du paquet Python. Le workflow de publication sera fourni dans le dépôt autonome. Cette branche conserve les sources et l’historique de développement, sans fusion dans le plugin.

La tentative de publication du 23 septembre 2026 a échoué lors de l’authentification PyPI ; elle n’a téléversé aucun fichier.
