# Cartomize Python Toolbox 10.5.1

Cette boîte à outils est directement utilisable dans ArcGIS Pro 3.7.

## Installation

1. Conservez `Cartomize.pyt`, `cartomize_core/` et `templates_library/` dans le même paquet extrait.
2. Dans ArcGIS Pro, ouvrez **Catalogue**.
3. Cliquez droit sur **Boîtes à outils** puis **Ajouter une boîte à outils**.
4. Sélectionnez `Cartomize.pyt`.

## Outils

- Contrôler la qualité cartographique du projet
- Créer automatiquement une carte
- Créer une mise en page Cartomize
- Analyser une couche vectorielle
- Analyser un raster avec Raster Engine
- Analyser le projet
- Produire une série de cartes Cartomize
- Rejouer une recette Cartomize
- Vérifier les changements MapOps

La boîte fonctionne avec l'environnement `arcgispro-py3` livré par ArcGIS Pro et n'exige aucune installation `pip`.

La symbologie et les mises en page restent dans le projet courant. Enregistrez l'APRX lorsque le résultat vous convient.
