# Installation

Cartomize 10.4.0-beta3 targets QGIS 3.40–3.99.

## Install from ZIP

1. Download the official Cartomize plugin ZIP.
2. In QGIS open **Plugins → Manage and Install Plugins → Install from ZIP**.
3. Select the ZIP and confirm installation.
4. Restart QGIS when replacing a previous development build.

No additional pip packages are required beyond the Python, PyQGIS, GDAL/OGR and NumPy components distributed with QGIS.
